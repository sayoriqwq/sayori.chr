# OpenKnowledge

## Border

一条内容放在哪里，看它换掉 OpenKnowledge、换一个仓库之后是否仍然成立：

- **仍然成立**：属于[理论](../theory/index.md)，写本源
- **只在这里成立**：属于本专题，写字段、文件、脚本与本仓的做法

理论不指向本专题。本专题指向它所落实的理论
