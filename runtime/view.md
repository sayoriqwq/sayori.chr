# View

本页落实[职责树的 Visibility](../theory/agency/crew.md#visibility)与 [Reentry](../theory/agency/crew.md#reentry)，定义 user 的控制面阅读视图与进出交互

## Surface

user 的控制面是终端对话与唯一的只读职责树视图，不另建图形界面，不在视图中放置批准或接收按钮：

- **统一入口**：容器层全局快捷键与普通终端查看命令打开同一只读视图，不维护第二套私有面板。无法可靠转发到同一视图的宿主入口不展示失效控件
- **零模型**：打开、切换、刷新、展开、进入与返回都只读记录与有界现场观察，不触发模型回合
- **单域范围**：视图严格限定当前工作区，不同工作区各有自己的视图与 Firstmate

## Tabs

顶部提供四个分类视角并附各自计数，每次聚焦一屏，按 user 认得的原诉求标识事项：

| 视角 | 内容 |
| --- | --- |
| 等你决定 | 目标为 user 的未决待决项，首行写决定什么，展开见背景、选项与代价，不附倾向 |
| 需要留意 | 破坏有主或一致性的异常、有明确影响的 Outside、已收口 Task 的遗留 Effect 或责任 |
| 诉求结果 | 显式关联的已完成诉求摘要与影响说明，便于回访，不代替 user 验收 |
| 进行中 | 未收口的活跃 Task，每项一行，展示名称与最近有效结论 |

> 例：曾因离开数天后状态视图按短时间窗口过滤为空、Mate 只能抛出决策清单与长简报，导致用户看不清整体与细节而无法判断

## Reading

选中事项后，详情区先回答怎么样了、等谁、下一步，再按需展开原据：

- **首层够用**：首层直接给出当前结论、等谁、下一步以及影响判断的阻断性例外，使用日常语言表达实际变化，不以内部协议术语替代用户价值
- **按需展开**：工作范围、Effect、关联 Station、原始汇报与证据路径按需展开。长文本正常换行，路径与原文可读到末尾
- **减法**：已有结局的失败、无遗留责任的缺报与已收口的 Task 退出主列表，不画空章节与无内容节点
- **诚实**：缺失、陈旧或不可读取的证据明确标为未知，读取失败显示计数未知，绝不伪装成零或已完成

> 例：曾有交付说明只堆内部登记术语与提交号而未说明实际变化，用户反馈看不懂做了什么

## Interaction

- **键鼠完整**：同时支持纯键盘与纯鼠标完整阅读。鼠标悬停只高亮不改选中项，列表区与详情区独立滚动，阅读位置不因展开收起跳回顶部
- **真实调节**：外框面积与内部分隔调节仅暴露宿主真实支持的能力，不在内容区画假控件，布局偏好存于本机本地状态
- **状态栏**：具备原生状态栏的宿主在各 Station 常驻显示当前 Station 身份标签，待决与留意计数为零时隐藏，非零或读取失败时显示

## Navigation

- **直接聚焦**：从视图进入运行中的 Station 时直接聚焦目标窗格，不中断进程，不靠搬移或缩放窗口破坏原有布局
- **同键返回**：使用同一全局快捷键或返回上个窗格时回到视图原位置。若原条目因已处理而消失，顺延到同一分类的下一条或下一个非空分类
- **历史恢复**：进入已退出的历史 Station 须通过显式恢复动作打开原会话，阅读与导航本身不触发派活、交回或验收
