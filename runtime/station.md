# Station

本页落实[职责树](../theory/agency/crew.md)的 Station、专业、入口、焦点与分支协议

## Identity

- **作用域**：Firstmate 固定为工作区根作用域，其余节点按所属 Task 与节点标识构成层次作用域。上层作用域在派活或分出时固定，同一 Station 更换[会话](../theory/agency/session.md)时保持不变
- **显示**：界面标明角色与所属作用域，Sailor 额外标明专业
- **专业**：Sailor 内置五类默认专业，类型定义对消费工作区保持开放以支持按领域扩展：

| 专业 | 职责目标 | 交付物 |
| --- | --- | --- |
| 实现 | 完成指定的代码或配置改动 | 提交或草稿 PR、验证证据与 Effect |
| 审阅 | 对照规范与 Spec 只读核查改动质量 | 分级问题清单与依据 |
| 质量验收 | 在真实环境核验整体可用性与用户路径 | 实际观察、复现步骤与证据缺口 |
| 诊断 | 定位问题根因与因果链，保持现场只读 | 因果证据、Fact 与 Inference 分列、最小修法候选 |
| 调研 | 查明外部方案、官方做法与约束条件 | 带出处的结论、适用条件与未核部分 |

审阅与质量验收由独立于同一张 Ticket 实现者的节点担任。确需动手做实验时，按[实证探索](../theory/communication/probe.md)有界执行并收回

## Entry

- **单一入口**：user 在终端前台执行 Firstmate 入口命令。机制核对本工作区本地状态，存在可恢复会话且无活实例冲突时直接续上原会话，无绑定时直接登记并启动新会话
- **显式换代**：提供显式换新入口，确认旧实例正常退出且进程消失后，以新会话接替 Firstmate 作用域。旧会话文件保留供回查，未结责任与在途回执沿同一作用域继续，原批准随工作核对而非隐式复制
- **唯一性**：同一工作区同一时刻仅运行一个活 Firstmate 实例。冲突核验基于真实进程存活与统一互斥锁，拒绝时直接输出具体原因

## Recovery

系统重启后由协作层独占恢复入口，容器专注承载进程与布局。恢复按以下步骤执行：

1. 核对容器服务端已关闭原生续会话能力，未确认时明确阻塞
2. 按职责树分级恢复：先恢复 Firstmate，再恢复存在未结工作的 Mate，Sailor 仅按 user 明确选择恢复。已匹配的活实例保持原样，缺原始会话或现场冲突时直接报告阻塞
3. 先令原会话恢复可交互状态，再按最新汇报与待决项接续工作。恢复的边界限于令原节点重新在线，派活与验收状态保持原貌

## Focus

每个 Station 在本地状态维护一行[焦点](../theory/primitive/focus.md)，更换会话时随 Station 接回。在具备原生扩展的宿主中常驻显示在待办清单上方并支持独立折叠，与宿主自带的会话待办各自独立维护：

- **实质更新**：仅在明确切换主题时由当前 agent 随正常对话更新一次，同题多轮保持静默
- **转场清空**：user 明确将旧事交后台处理且尚未开启新题时，清空前台焦点，待首个明确新题出现再写入
- **后台隔离**：后台交回、通知与回执独立进入待办通道，保持当前前台焦点稳定
- **顺问提示**：偏离已记焦点时，agent 照常回答并在首行提示可用 `/branch` 分出，保持原焦点稳定，由 user 决定是否分出

> 例：user 将收口工作移交后台并转聊新事务时，焦点仍停留在旧主题导致定位漂移，见[焦点滞留与重载重复唤醒](../cases/focus-drift-reload-replay.md)

## Branch

`/branch` 由 user 发起，将当前会话中偏题的一段对话分到独立 Station，全过程零模型调用：

- **语义边界**：命令与所附自然语言专责选定讨论主题与方向。实施、迁移与资源动用归属[批准](../theory/agency/approval.md)，二者各自独立核对。无偏题提示的裸命令先向 user 澄清目标
- **执行步骤**：
  1. **记录阶段**：以偏题的 user 消息为锚点分叉新会话，写入新 Station 登记，最后裁剪原会话退回到锚点之前。任一前置步骤失败时原会话保持完整原样
  2. **启动阶段**：同一 Task 下的新话题在原 Station 下登记为子 Mate，并在所属 Task 的容器工作区后台静默新开单窗格标签页恰好一次，保持 user 焦点留在原窗格。属于新话题时交 Firstmate 免批承接为独立讨论节点，聊出正式工作后再按 user 决定登记新 Task，启动失败明确显示未启动
  3. **首轮阶段**：新会话接收转送的原话后按正常对话展开
- **作用域隔离**：分叉后的两个会话各自独立演进，结果经事件存储回到所属 Task。新 Station 拥有独立的身份、会话待办与资源边界，已有批准按[批准的 Transfer](../theory/agency/approval.md#transfer)对照原据核对

> 例：分叉命令附带自然语言讨论目标曾被当作新任务实施批准门槛，导致正常分出讨论受阻，见[分叉讨论目标误作实施批准](../cases/branch-goal-approval.md)
