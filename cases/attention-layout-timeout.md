# Attention Layout Timeout

## Expected

派活记录写入事件存储后立即完成送达确认，终端布局调整与事件持久化各自独立判定

## Actual

盘点节点派活已成功送达且事件已落盘，但在提交待决项的同时隐式触发了容器移窗操作并发生五秒超时，命令向调用方返回超时错误

## Evidence

- 原始案例：消费区事件序号 113，标识 `residue-audit-attention-timeout`，记录于 2026-11-19
- 后台任务退出码为零且派活记录已写入，错误输出显示布局同步超时

## Inference

事件存储适配器混入了容器布局副作用，破坏了持久事件存储端口与容器运行时端口的边界
