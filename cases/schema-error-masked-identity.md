# Schema Error Masked Identity

## Expected

写入事件存储的汇报可被同一读取契约正确解码，身份核验仅检查本地绑定与目标事件，任何解码失败直接报告具体字段位置

## Actual

汇报写入放行了新字段，但读侧严格校验拒读该事件。身份核验先读取全量历史事件，并将底层结构解码失败统一包装为身份校验失败，导致整个 Firstmate 工具链全面不可用

## Evidence

- 原始案例：建设区事件序号 1561，标识 `sais-old-identity-reader-rejects-outside-impact`，记录于 2026-11-20
- 实测同一条含新字段的汇报事件在旧版读侧报结构校验错，而实际会话绑定与终端身份均正常一致

## Inference

写入与读取未守住对称契约，同时身份核验误用全库解码并吞掉了底层错误原因
