# Git Hygiene Gap

## Expected

无论在哪一个工作区，agent 均遵循统一的 Git 卫生规范，按期清退已合入工作树、区分活跃改动与旧草稿，并保持版本跟踪边界清晰

## Actual

消费工作区缺少统一的工程卫生规范，导致已合入工作树长期滞留、旧草稿改动被误判为活跃进展、交接与台账文档被忽略白名单挡住、嵌套独立仓库显示为未跟踪且测试证据长期积压

## Evidence

- 原始案例：消费区事件序号 393，标识 `mate-git-hygiene-gap`，记录于 2026-11-23
- 当日盘点核实了多棵已合入未清退工作树、旧草稿分支、忽略白名单冲突与嵌套独立仓库未跟踪现象

## Inference

上述问题全部换任意工作区均原样成立，缺口属于工程层基座规范缺失，应在工程层统一制定并由各消费工作区遵守
