# Storage Contract Mismatch

## Expected

存储读写修复在单元测试通过后，经真实对象存储与文件系统挂载路径验证，由真实消费者成功读取并消费同一份产物

## Actual

单元测试使用的内存流替身接受带长度参数的读取调用，且独立的字典模拟与本地临时目录未反映对象上传后在挂载目录即时可见的关系。测试全绿后进入真实运行环境时，真实对象存储客户端仅支持无参读取调用，导致实际产品调用失败。另有一次调查通过人工注入超时异常复现半删状态，随后在正常并发与真实界面路径下并未复现原症状

## Evidence

- 消费区实战复盘记录于 2026-10-28 与 2026-10-30，核对源码测试、真实对象存储读取诊断与受控发布复测四份原始记录
- 内存流替身接口签名与真实对象存储客户端存在参数差异，人工故障注入表现与真实用户路径表现存在分歧

## Inference

内容完成、接入完成与真实使用验证是三个独立层次。测试替身绿灯与人工故障注入均只证明设定条件下的局部反应，验收必须沿真实消费者路径核对完整契约
