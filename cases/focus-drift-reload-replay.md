# Focus Drift Reload Replay

## Expected

user 明确将收口工作移交后台并转聊其他事务时，前台焦点及时清空并在新主题出现时切换。同一会话重载后，已送达过的待决项保持业务可查而不再重复唤醒模型

## Actual

user 明确表示转聊其他事务并展开新工作后，Station 焦点仍停留在收口主题。同时同一会话重载后，先前已经送达的旧待决项再次触发模型新回合

## Evidence

- 原始案例：建设区事件序号 1142，标识 `background-work-anchors-focus-reload-replays`，记录于 2026-11-19
- 观测记录显示旧实现的已送达集合仅存于内存，会话启动观察时直接以触发新回合的方式重复发送

## Inference

前台焦点缺少放下旧题的清空语义，通知观察器将业务未结与通知已送达混为一谈且未持久化送达状态
