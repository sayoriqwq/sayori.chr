# Premise

## Facts

### User

| Fact | Meaning |
| --- | --- |
| user 负责，却不一定在场 | 结果由 user 负责，user 却按自己的节奏进入或离开 |
| user 的注意力极其有限 | 只能同时关注少数几件事，无用的信息同样在消耗它 |
| user 无法把预期完整表达出来 | 只能尽量表意，再经对齐使理解一致。user 自己也可能还不确定，所以预期会变 |
| user 会偷懒 | 有现成的答案，就容易不经思考地接受 |

### Agent

| Fact | Meaning |
| --- | --- |
| agent 短暂 | 行动者会结束，上下文会消失，行动留下的东西却还在 |
| agent 不会从经验中学习 | 行为只由模型和给它的上下文决定。同样的错误下次照样犯，除非改变给它的东西 |
| agent 的上下文有限 | 每一项内容都占位置，无关的内容同样在消耗它 |
| agent 会出错，而且说得很有把握 | 做错和做对，它的报告读起来一样，它自己的说法证明不了做完了 |
| 程序做硬机制，模型做软语义 | 程序由确定性代码定义硬边界，精确可重复且违背即错，适合承载流程中核心不可动摇的不变量。模型遵循具有概率性，由上下文引导处理软边界、按现场情境扩展以及难以用程序穷尽的复杂度取舍。两者不分好坏，只按用途分界 |

### Environment

| Fact | Meaning |
| --- | --- |
| 现状只有环境自己知道 | 描述它的记录、记忆与总结都会过时，环境不会 |
| 外部环境与他人共享且部分变化不可逆 | 行动可能波及他人与共享资源，部分改动一旦发生便无法撤回或产生并发冲突 |

事实描述世界是什么样，不取决于本理论怎样设计。换一套协作方式，它们照样成立

## Inputs

前提与[原语](primitive/index.md)同级，和 user 的偏好、决定一起，是各领域的输入：

- **事实**：世界是什么样
- **原语**：上层理论在说什么
- **偏好**：条件等同时，user 倾向的方式。例如两种命名风格等价时，喜欢哪个就是偏好
- **决定**：条件不等时，user 选定的去向，对应[效力的 Form](primitive/validity.md#form)

审阅一条规则时，核对它出自哪个事实、用了哪个原语、哪一部分是 user 的偏好或决定。这些都答不出来的内容需要重新评估或删去

> 例："任何时刻一件事恰好有一个负责人"，出自"agent 短暂"，用的是 [Ownership](primitive/ownership.md)。"默认在场当场问"是 user 的决定

目录按读者遇到的问题组织，事实说明规则为什么成立，两者交叉。每个领域在自己的 index 写明出自哪些事实，本页不汇总

## Admission

新事实经 user 确认后加入，它要满足：

- **独立**：不依赖本理论的任何设计
- **有用**：至少推出一条领域规则
