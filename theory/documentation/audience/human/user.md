# User

user 即 sayori

## Judgment

需要 user 判断的事放在最前面：agent 查明的事实与分析结论、关键取舍，以及哪些事等 user 决定。等 user 决定的点只写理由与代价，不写倾向，见 [Leadership](../../../communication/leadership.md)。概览足以让 user 理解局面并决定看哪里

## Review

user 审阅时，事实、推断、提议与已确认内容一眼可辨，标法见[效力](../../../primitive/validity.md#form)。agent 的提议与 user 的决定分开写
