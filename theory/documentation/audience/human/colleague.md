# Colleague

colleague 指 user 的技术同事：对所在项目与相关技术内容有基础认知

## Baseline

基础概念、通用技术与项目背景直接使用，篇幅留给定义

## Definition

文档的重心是定义，这份文档承担哪个就写哪个：

- **问题的定义**：什么现象、在什么条件下、与什么预期不符，或要达到什么结果
- **验证的定义**：怎样核对问题存在，怎样核对问题已经解决

定义写到可以独立检查的程度。候选方案作为线索，与定义分开写。两个定义怎样按文档拆开，见 [Delivery 的 Definition](../../../delivery/index.md#definition)

## Shared

colleague 与 user 共读的文档，例如 [Issue](../../../delivery/issue.md)，同时满足 [User](user.md) 的要求：重点先行，需要 user 判断的事放在前面
