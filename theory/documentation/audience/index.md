# Audience

## Readers

| 读者 | 读文档为了 | 要求 |
| --- | --- | --- |
| human | 理解与判断 | [Human](human/index.md)：user 与 colleague |
| agent | 定位内容与执行 | [Agent](agent.md) |

目标读者由文档用途确定：用途服务谁的理解、判断或行动，谁就是目标读者。[书写](../writing.md)的规则对所有读者都成立，读者页只写该读者特有的要求

## Shared

理论由 user 与 agent 共读：user 据此理解和判断，agent 据此定位、研究和派生。[User](human/user.md) 与 [Agent](agent.md) 的要求同时满足。要求冲突时，以文档用途决定哪类读者优先，并与 user 确认

## Deliverable

产物只承载其目标读者需要的内容。制作理由、使用方法、待核对事项等给委托者的说明，写在交付反馈或独立说明中

> 例：user 要一份汇报 HTML。HTML 只放汇报内容，编排理由与使用建议写在交付反馈里
