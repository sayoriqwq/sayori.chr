# Identity

## Condition

建一份 Skill，起点是观察到的跑偏：没有它时 agent 会怎样做偏，为什么下次还会这样，在哪里介入能改变过程。任务类别只说明做什么，能力只说明能不能做，都不是成立条件

只提供能力或背景知识、不约束做事过程的内容，不属于这里说的 Skill。宿主可能用同一种载体装它们，载体相同不等于对象相同

Skill 约束的是过程：相似情境下，在哪里核对、走哪条路、什么时候停。它不保证结果正确，结果按 [Acceptance](../delivery/acceptance.md) 核对

## Responsibility

一份 Skill 承担一个治理责任。一个责任可以有多个步骤，也可以持续一个阶段，只要这些步骤对付同一种跑偏，用同一个标准核对做得对不对

跑偏的种类、允许的动作或成功标准可以各自独立变化时，就是两个责任，分开成两份

## Boundary

| Situation | Form |
| --- | --- |
| 输入、路径和结果都能写死 | 程序 |
| 还要靠模型辨认情境、选择信息或推断够不够 | Skill |
| 选错就无法挽回的转向点 | Skill 外面加机制，见[派生的 Fidelity](../evolution/derivation.md#fidelity) |
| agent 不加约束也能稳定做好 | 什么都不做 |

没有观察到的跑偏时，不建 Skill 是正常结果，目录空着不算缺陷
