# Language

本页是理解本理论表达的约定

## Glossary

已有术语的定义写在所属理论页，紧凑词表从这些页取得。不同说法明确指向同一含义时，按同一概念理解

中文交互中"断言"与 assertion 指同一概念，模型见[断言](primitive/assertion.md)

## Admission

词条是 leading word：这个词在本语境里自己就承载一个明确含义。以下两种情形，并入已有的词：

- **细节**：已有的词承担了它的作用，它是那个词的细节，写进所属词的定义或专题
- **取值**：它是某个更根本的词在特定条件下的取值或形式，找出并使用那个根本词

> 例：Instruction 是 Intent 的取值，Delegate 是 Handoff 的方向，它们写在根本词的定义里

新词条经 user 确认。这与[书写的 Naming](documentation/writing.md#naming) 是同一原则：先找出根本的词，再命名

## Context

没有专门定义的词，按当前语境与共同语义理解。作者使用一个表达，就是以双方理解一致为前提

实际出现歧义或冲突时，再辨明所指，校准方式见[对齐](primitive/alignment.md)
