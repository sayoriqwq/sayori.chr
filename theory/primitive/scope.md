# Scope

作用域是一个对象在指定维度上的覆盖范围。它总是某个对象的范围，从当前语境辨认正在讨论谁的

## Dimension

维度说明当前在问什么：

| Dimension | Question |
| --- | --- |
| 内容范围 | 这份内容负责处理什么 |
| 工作范围 | 这件事算不算这次工作 |
| 观察范围 | 实际核对了什么 |
| 批准范围 | 允许改变什么 |

每个维度的结论只用于本维度

> 例：查阅一个对象属于观察范围，修改它需要批准范围覆盖。获准修改之后，影响是否已全部核对，仍看观察范围

范围之外的内容仍可能存在、仍可能重要。当前没讨论的问题可能要紧，没核对的变化可能已经发生

## Border

边界是范围到哪里为止，凭什么和相邻对象区分。主要说明这里实际负责什么，"不负责什么"只用来排除混淆

边界清楚的对象之间可以有重合。同一内容服务不同对象时，按各自职责辨明用途，保留必要的联系

位置可以表达已经辨明的归属，依据仍需说明

## Reuse

引用建立关联，原内容的效力与适用范围保持原样

只提取结论会丢失成立条件时，连同必要的条件一起取得。压缩、引用或导出之后，局部成立的认识仍带着它的条件
