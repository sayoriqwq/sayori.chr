# Primitive

## Selection

原语和[前提](../premise.md)同级：前提说明世界是什么样，原语说明上层理论在说什么，各领域由两者加上 user 的偏好与决定推出

一个概念够不够格，用删除测试：拿掉它，上层规则的意思还说得清吗。被引用多少次不算依据。它还要能单独说清，不依赖任何领域，也不依赖载体，只属于某种文件的形式不是原语

反过来也要查：上层依赖却没有定义的意思，说明缺一个原语。user 的偏好与决定写在领域里，不写进原语

## Primitives

| Primitive | Description |
| --- | --- |
| [判断](judgment.md) | 判断是什么、只属于谁，它和核对、推断、选择、主张怎样区分。读到"判断归 user"，或拿不准一件事该自己做还是该问 user 时读 |
| [上下文](context.md) | 一方此刻实际手上有什么，为什么写在别处不等于它知道。agent 的行为出乎意料、拿不准某项内容 agent 能不能看到，或要决定给 agent 什么时读 |
| [作用域](scope.md) | 说清一件事管到哪里、凭什么和相邻的事区分，引用别处内容时不越界。拿不准某项内容归不归当前对象，或要复用另一处的规则时读 |
| [断言](assertion.md) | 怎样把一个主张说得简明，以及它在文档里放在哪里。写页面的 assertion，或要概括一个主张时读 |
| [上下文指针](context-pointer.md) | 怎样写链接和引用，让读者知道为什么读、什么时候读。写链接、引用或给 agent 的读取入口时读 |
| [焦点](focus.md) | 当前讨论围绕什么，怎样辨认话题跑偏。讨论越展越开，拿不准还在不在回答原问题时读 |
| [对齐](alignment.md) | 怎样知道双方理解一致，到什么程度算够。对话中怀疑有误解，或拿不准 user 的意思时读 |
| [负责](ownership.md) | 一件事现在归谁，怎样转交，负责到什么时候为止。交接、委派、负责人中断，或拿不准某件事现在归谁时读 |
| [记录](record.md) | 什么要写到外面，写成流水还是当前状态。内容要活过当前 Session、写日志或状态，或拿不准该追加还是改写时读 |
| [效力](validity.md) | 现在实际怎样以什么为准，一条信息有多大约束力：是事实还是推断，是提议还是已确认，凭什么算数。引用旧决定、拿不准一条规则是否仍有效，或要说明一个结论的证据时读 |
