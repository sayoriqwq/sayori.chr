# Context Pointer

上下文指针是从当前内容指向所需材料、并说明其用途或读取条件的引用。链接是常见载体，指针同时承载读取目的与触发条件

## Relation

目标可以是一份文档、其中的片段，或其他可辨认的内容，可以位于任何存储位置

用途可以由当前表述直接说明，也可以从已经清楚的上下文取得

> 例：查定义、理解背景、查看依据，是三种常见读取用途

## Scope

指针给出入口，读取、理解与核对各是后续独立的一步。被引用内容的约定在当前场景是否生效，按[作用域的 Reuse](scope.md#reuse)核对

读取多少、何时读取、是否自动加载，由使用指针的一方按自身上下文预算决定

## Position

位置表达归属，指针表达跨位置的具体关联。一段表达可以同时承担[断言](assertion.md)与指针两种角色
