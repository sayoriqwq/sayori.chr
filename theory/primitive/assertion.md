# Assertion

断言是简明表达关键主张的内容，可以采用关键词、句或段。它的成立不依赖 Markdown 文件

## Wording

- **关键词**：能在当前语境中唤起所指主张时，直接使用
- **句或段**：关键词不足以表意时补足

断言可以是一句目录说明、会话中的一句话，或正文中的短段。字数、句式与存放位置不决定它是不是断言

## Context

断言让所指对象及必要限定可辨，已经清楚的上下文不必重复。局部成立的主张保留其条件，见[作用域的复用](scope.md#reuse)

> 例："当前资料不足以支持这个结论"，表达的是对当前资料的主张，范围限于当前资料与这个结论

## Validity

断言表达一个主张，它的 Form 与 Stage 按[效力](validity.md)另行标明：核对、确认与批准各需自己的依据

## Distinctions

- **[焦点](focus.md)**：定位当前会话围绕什么讨论，可以是一个问题
- **断言**：表达关键主张
- **[上下文指针](context-pointer.md)**：提供取得相关材料的入口

一段表达可以同时是其中几种

## Document

在文档中，每篇文档有一处断言，是本页核心主张的唯一真源，可以是两三句自然的话，放在读者最先看到的位置。它和 description 怎样分工，见[组织的 Entry](../documentation/organization.md#entry)
