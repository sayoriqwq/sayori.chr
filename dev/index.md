# Dev

## Position

本仓的[愿景](../VISION.md)确立最高价值目标与取舍标尺，[理论](../theory/index.md)声明全部跨实现恒成立的原理，[协作层](../runtime/index.md)定义协作引擎的上游设计，本目录定义成品工作区基座的上游设计。工作区基座作为可直接实例化或扩展的基础装配方案，把协作引擎接入、静态基座配置、确定性检查机制与独立工程 Skill 组装为轻量化工作区底座

## Realization

依据 [Skill 的 Boundary](../theory/skill/identity.md#boundary) 与 [派生的 Fidelity](../theory/evolution/derivation.md#fidelity)，上游理论在工作区基座中的规约实现按决策性质分流到三类载体：

| 载体 | 适用条件 | 在工作区基座中承载的内容 |
| --- | --- | --- |
| 静态基座配置 | 打开工作区即恒常成立的结构、入口骨架、扩展槽与默认边界 | 工作区薄入口骨架、单层平铺任务区约定、按职责分层的忽略模板、协作层接入配置 |
| 确定性检查机制 | 流程中核心不可动摇、可由代码定义硬边界且违背即错的约束 | 工作树残留与合入巡检、忽略与大体积产物阈值核验、Skill 包自包含边界与链接自检 |
| 独立工程 Skill | 存在可复发跑偏、属于软边界或须由模型按现场做软语义处理与复杂度取舍的工程动作 | Git 收口清退、Delivery 阶段汇报与工程验证等有真实案例支撑的独立可分发包 |
