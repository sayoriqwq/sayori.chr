# Dev

## Position

本仓的[理论](../theory/index.md)声明全部跨实现恒成立的原理，[协作层](../runtime/index.md)定义协作引擎的上游设计，本目录定义成品工作区基座的上游设计。工作区基座作为可直接实例化或扩展的基础装配方案，把协作引擎接入、静态基座配置、确定性检查机制与独立工程 Skill 组装为轻量化工作区底座

| 层级 | 位置 | 职责 |
| --- | --- | --- |
| 理论真源 | [theory/](../theory/index.md) | 沟通、Agency、交付、文档、Skill、Git 与进化的全部原理 |
| 协作层设计 | [runtime/](../runtime/index.md) | 协作引擎的协议状态机、存储端口、唤醒、视图与宿主扩展 |
| 工作区基座设计 | 本目录 | 成品工作区装配方案：接入协作层，提供基座配置、检查机制与自包含工程 Skill |
| 具体工作区 | 各消费工作区实例 | 基于基座扩展的薄业务层：仓库拓扑、环境合同、领域知识、Task 与薄适配 Skill |

全部理论正文、建模论证与工程 Skill 的理论出处集中维护在本仓。工作区基座的下游实现交付面向运行时消费的派生配置、检查机制与独立自包含 Skill 包，在 sayori 中具体由 `sayori.dev` 承载

## Realization

依据 [Skill 的 Boundary](../theory/skill/identity.md#boundary) 与 [派生的 Fidelity](../theory/evolution/derivation.md#fidelity)，上游理论在工作区基座中的规约实现按决策性质分流到三类载体：

| 载体 | 适用条件 | 在工作区基座中承载的内容 |
| --- | --- | --- |
| 静态基座配置 | 打开工作区即恒常成立的结构、入口骨架、扩展槽与默认边界 | 工作区薄入口骨架、单层平铺任务区约定、按职责分层的忽略模板、协作层接入配置 |
| 确定性检查机制 | 输入、路径与判定规则完全确定，须在中断与疏忽下稳定守卫的约束 | 工作树残留与合入巡检、忽略与大体积产物阈值核验、Skill 包自包含边界与链接自检 |
| 独立工程 Skill | 存在可复发跑偏，且须由模型辨认上下文语义并组织流程的工程动作 | Git 提审整合与收口清退、Issue、PR、Stack PR、Release、验证与阶段交付等独立可分发包 |
